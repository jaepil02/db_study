이 문서는 **D-NN의 채번 정본**이다. D는 제품·학습 결정 — 무엇을 배우려 하는가 · 무엇을 만들지 않는가 · 어떤 순서로 재는가 · 측정을 어떻게 기록하는가 — 를 고정한다. **기술 결정(어떤 런타임 · 저장소 설정 · 큐 · 모듈 구조를 택하는가)은 ADR-NN이며 [../04_architecture/09_decision_records.md](../04_architecture/09_decision_records.md)가 채번한다.** 여기서 ADR을 채번하지 않고, D가 정한 방향의 기술 세부를 여기서 재론하지 않는다(경계는 §D와 ADR의 경계).

**D 총수는 13건**(D-01~D-13 · 결번 없음)이다. 세는 자리는 §결정 색인 하나이며 루트 README 고정 기준은 이 수치를 인용한다. 채번 규칙은 셋이다.

- 각 결정은 **맥락 · 결정 · 버린 대안과 그 실패 · 파급**을 함께 적는다. 버린 대안의 이유가 남지 않으면 같은 논의가 반복되거나 결정이 조용히 뒤집힌다.
- **뒤집힌 결정은 지우지 않는다.** 대체되면 결정 칸 첫머리에 상태 한 줄(대체됨 → D-NN)을 두고 원문을 보존한다. 번호는 말미 채번 · 재배치 금지 · 폐지 번호 결번 보존이다.
- **번호는 확정 순서이고 배치는 주제별이다.** D-01~D-05가 학습 목표와 문서군 구축의 전제, D-06~D-10이 원본 계획과 W0 보정에서 올라온 측정 체계, D-11~D-12가 W1이 원본 로드맵과 학습 목표를 맞추며 내린 판정이다. 아래 절은 주제로 묶여 번호가 절 사이를 건너뛴다.

## 결정 간 의존

결정은 서로를 전제로 선다. 위 결정을 뒤집으면 아래 결정의 근거가 흔들린다.

```plain
D-01 학습 목표 2축
├── D-04 3계층 분기                ← 목표 ②의 설계
│   └── D-11 업무 축 생략 불가      ← ③계층 시연 · ②계층 실행 자리
├── D-05 PostgreSQL 대조군         ← 목표 ①의 설계
│   └── D-12 대조군 단계 편입       ← 목표 ①의 실행 자리
└── D-06 스위치 1급 요구사항        ← 두 축의 공통 손잡이
    ├── D-07 학습 순서 재배열       ← 스위치를 달 경계를 먼저 만든다
    ├── D-08 SW-10 유지             ← 기록되지 않는 조건을 없앤다
    ├── D-13 SW-11 채번             ← 같은 이유로 최신값 갱신 주체도 스위치로
    └── D-10 4요소 · 3회 중앙값     ← 스위치 상태가 기록 4요소의 하나다
D-02 로컬 전용                      ← D-10의 3회 중앙값을 필수로 만든 환경
D-03 흡수 후 삭제                   ← 문서군 구축의 전제
└── D-09 측정 기록 예외 폴더        ← 흡수 대상에서 기록 자리를 뗀다
```

- **D-01을 뒤집으면 그 아래 트리 전체의 근거가 함께 흔들린다.** 학습 목표를 바꾸는 제안은 이 트리의 하위 결정을 같은 변경 단위에서 재판정한다.
- **D-02와 D-10은 인과로 묶인다.** 로컬 단일 머신이라 부하 생성기 · 관측 스택을 격리할 수 없고, 그래서 단일 실행 수치를 믿을 수 없다. 다중 머신으로 가도 D-10이 자동으로 풀리지 않는다 — 코어 배치 분산은 머신 수가 아니라 스케줄러의 문제다.
- **D-11 · D-12는 D-07의 틀 안에서만 움직인다.** 단계 번호를 늘리지 않고 기존 단계의 범위만 바꾼다.

## 재론 규칙

| 상황 | 규칙 | 어기면 |
|------|------|------|
| 다른 문서가 확정 결정을 서술해야 할 때 | 결정 문서를 링크하고 결론만 적는다. 버린 대안의 논쟁을 옮겨 적지 않는다 | 같은 논쟁이 여러 문서에 흩어져 한쪽만 개정되고, 개정되지 않은 쪽이 옛 결정을 계속 주장한다 |
| 결정을 뒤집을 때 | 새 D를 말미에 채번하고 옛 D에 상태 줄(대체됨 → D-NN)을 단다. 원문은 보존한다 | 왜 한 번 그렇게 갔다가 되돌렸는지가 사라져 같은 실수를 반복한다 |
| 결정의 수치만 바뀔 때 | 상태 줄에 "수치 개정"과 A → **B**를 적고 판정 축은 유지한다 | 수치 변경이 결정 전체의 대체로 오독된다 |
| W1 판정(D-11 · D-12)을 사용자가 뒤집을 때 | 상태 줄을 달고 [05_priorities_roadmap.md](./05_priorities_roadmap.md)의 단계 범위를 같은 변경 단위에서 되돌린다 | 로드맵은 옛 판정을, 결정 문서는 새 판정을 말한다 |
| 기술 결정이 D처럼 보일 때 | §D와 ADR의 경계의 판정 기준으로 가른다. 애매하면 ADR로 보내고 D는 방향만 링크한다 | 같은 결정이 D와 ADR 양쪽에 채번되어 정본이 둘이 된다 |
| 실측이 결정의 전제를 깰 때 | 결정을 조용히 고치지 않고 실측 기록을 근거로 새 D 또는 상태 줄을 단다 | 결정 문서가 as-built와 어긋난 채 남는다 |
