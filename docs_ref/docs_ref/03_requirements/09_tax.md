v1의 신고 범위는 **기한 알림 + 퇴사 관련**으로 한정한다. 원천징수이행상황신고 · 지급명세서 · 연말정산 · 중도퇴사자 정산 · 보수총액신고 · 일용근로내용 확인신고서는 v1에 두지 않는다.

**자동 제출은 하지 않는다.** 산출 범위는 EDI 업로드용 데이터 생성까지이며, 실제 제출은 사용자가 홈택스·4대보험 EDI에서 수행한다. 기능을 만들지 않는 것과 **잘못된 값을 조용히 내는 것**은 다르므로, 미지원 범위는 명시적으로 고지하고 계산 결과에 영향을 주는 미지원 항목(두루누리 등)은 결과 화면에 표기한다(REQ-TAX-05).

퇴사 한 건이 세 종류의 시계를 예고한다 — **4대보험 상실신고(적용 보험 중 가장 이른 기한 — 건강보험 14일 · 그 밖 다음달 15일) · 이직확인서(요청일 + 10일) · 금품청산과 퇴직금 지급(퇴직일 + 14일)**이다. **다만 시작 사건은 같지 않다.** 상실신고와 14일 시계는 퇴직 사실에서 곧바로 기산하므로 퇴사 확정이 과제를 만들지만, **이직확인서 10일 시계는 근로자가 발급을 요청한 날부터 기산하므로 요청 접수 시점에 과제가 생긴다** — 기산일과 기한은 만들어진 뒤 고칠 수 없으므로, 아직 일어나지 않은 사건을 기준으로 미리 행을 만들면 기한이 사실과 다른 값으로 굳는다. 이 시계들의 감지는 정기작업이 담당하며 **실행 시각이 아니라 기준일 파라미터로 동작**해 재실행 시 같은 결과를 낸다. 전역 계약은 [01_global_rules.md](./01_global_rules.md)를 전제한다.

| REQ-TAX-01 | 4대보험 취득·상실 신고자료 | 입·퇴사마다 자격취득·상실 신고서 데이터를 생성한다(**EDI 업로드용 산출까지이며 자동 제출은 범위 밖**이다). 입력은 보험별 가입 대상 판정(REQ-PAY-21) · 취득일 · **상실일**(최종 근무일 기준이며 퇴사일과 구분한다) · 보수월액 · 사업장관리번호다. **취득·상실신고 기한은 보험별로 갈리고 과제 기한은 적용 보험 중 가장 이른 값**이다 — 건강보험만 그 날부터 14일(국민건강보험법 §8② · §10②)이고 국민연금·고용보험·산재보험은 다음 달 15일이다. **적용 보험은 인사 적용정보가 정하되 적용정보가 없으면 넷 전부**로 보며, **적용 보험의 기한 키 중 하나라도 없으면 과제를 만들지 않는다**(부분 파생 금지). 조문 출처는 [18_official_references.md](./18_official_references.md) · 파생 규칙은 [../05_database/12_compliance.md](../05_database/12_compliance.md)가 정본이다. **보험관리번호의 보유처는 사업장이다** — 고용보험과 산재보험이 사업장(장소) 단위로 성립하므로 번호도 직원이 아니라 사업장에 붙으며, 직원별 보험 적용정보는 가입 여부·취득일·상실일·보수월액만 갖는다. **번호 축은 보험 계열마다 다르므로 하나로 합치지 않는다** — 고용·산재는 사업장관리번호를 공유하지만 국민연금과 건강보험은 각각 별도의 사업장 식별번호를 쓰므로, 계열별 번호를 담을 축이 없으면 4종 신고서 중 일부가 틀린 번호로 생성된다. 번호가 없으면 해당 보험의 자료 생성을 막고 사업장 설정으로 안내한다 | MANAGER · 서버 | P1 |

### v1 범위 밖 — 차단·고지 대상

기능을 만들지 않는 것과 잘못 계산하는 것은 다르다. 아래는 REQ-TAX-05가 고지 대상으로 삼는 항목이며 **조용히 틀린 값을 내지 않도록 차단·고지가 필요**하다. v1 제외 기능ID의 등재 정본은 [../01_overview/02_goals_scope.md](../01_overview/02_goals_scope.md) Out 범위 표이며 본 절은 계산·고지 계약만 다룬다.

| 항목 | v1 처리 |
|------|--------|
| **일용근로자(DAILY) 급여·원천징수** | 고용형태 DAILY는 **급여 계산 대상에서 제외하고 명시적으로 차단**한다. 일용 분리과세·소액부징수를 구현하지 않은 채 상용 로직으로 계산하면 세액이 틀린다. 온보딩에서 고용형태를 물어 사전 안내한다 |
| **두루누리 사회보험료 지원** | 지원 대상이면 근로자 부담분까지 지원되어 **공제액과 명세서 금액이 실제와 달라진다**. 계산 결과에 확인 안내를 표기하고 결과에 적용 여부 필드를 미리 둔다(REQ-GLB-10) |
| **원천세·지급명세서·연말정산** | 미지원을 고지하고 기한 캘린더(REQ-TAX-03)로 안내한다. 지급명세서는 **2027-01 지급분부터 매월 전환이 확정**되어 있으므로 향후 산출 단위를 처음부터 **월**로 설계한다 |
| **포괄임금·고정OT** | 포괄임금 계약 사업장은 v1 대상이 아님을 고지한다. 실근로 가산과의 차액 산정을 구현하지 않는다 |
| **휴업수당** | v1 범위 밖이다 |

## 관련 테이블

| 테이블 | 역할 |
|--------|------|
| compliance_tasks | 기한 과제 원장 — 상실신고·금품청산·퇴직금 시계는 퇴사 확정이, **이직확인서 시계는 요청 접수가**, 원천세 과제는 급여 확정 부수효과가 만든다. 규모 판정 스냅샷 식별자를 동결한다(REQ-TAX-02·03·04) |
| employee_insurance_infos | 취득일·상실일·보수월액 — 신고자료의 직원 축 입력(REQ-TAX-01) |
| workplaces | **보험 계열별 관리번호**와 **원천세 납부 주기 설정** — 신고자료의 사업장 축 입력이자 원천세 기한 파생의 첫째 축(REQ-TAX-01·03) |
| employees | 퇴사일·최종 근무일·이직사유 — 상실일과 이직확인서의 입력(REQ-TAX-01·02) |
| payroll_employee_results | 평균임금·피보험단위기간 산출 근거 — 이직확인서 재사용(REQ-TAX-02 · REQ-PAY-09) |
| severance_assessments | 퇴직금 판정·기한 — 14일 시계의 원천(REQ-TAX-03) |
| statutory_rates | **신고 기한 정책값 전용 category**와 SIZE_POLICY 조회 — 원천세 기한 파생의 둘째 축(REQ-TAX-03) |
| documents | 신고자료·이직확인서 산출물의 실체·파일 해시·보존기한. **분류는 보험 문서 축을 쓴다**(REQ-TAX-01·02) |
| notifications | 기한 사전 알림 compliance_deadline. **(과제, 임박 구간) 단위 중복 억제**(REQ-TAX-03·04) |

## 관련 화면

| 화면 코드 | 화면명 |
|-----------|--------|
| ADM-TAX-FILING | 4대보험 취득·상실 신고자료 |
| ADM-TAX-SEPARATION | 이직확인서 |

검산: 3본 — 전부 ADM이다. v1 미지원 신고 범위의 고지는 ADM-DEADLINE-CALENDAR가 담고, 기한 감지(REQ-TAX-04)는 화면 없는 (배치) 축이다. **자동 제출 화면을 만들지 않는다.**

기능→화면 전수 매핑 정본은 [../07_screen/02_traceability.md](../07_screen/02_traceability.md)다.

## 에러 코드

**TAX 도메인은 전용 에러 코드를 두지 않는다.** 신고자료 산출은 인사·급여·보험 데이터를 읽어 문서를 만드는 경로라, 실패 원인이 모두 상위 도메인의 코드로 표현된다. 이 도메인에서 실제로 발생하는 코드는 아래와 같으며 정의처는 각 도메인 파일이다.

| 에러 코드 | HTTP | 발생 조건 |
|-----------|:--:|----------|
| **workplace.mgmt_no_required** | 422 | 대상 보험 계열의 **사업장관리번호 부재** — 비어 있는 계열을 details로 반환한다. 정의처 [03_workplace.md](./03_workplace.md)(REQ-TAX-01 · REQ-WRK-09) |
| payroll.severance_source_missing | 409 | 이직확인서·퇴직금 산출에 필요한 확정 급여 부재 — 정의처 [07_payroll.md](./07_payroll.md) |
| payroll.missing_reference_value | 422 | 신고 기한·규모 정책 기준값 누락 — 정의처 [01_global_rules.md](./01_global_rules.md) · [07_payroll.md](./07_payroll.md) |
| common.not_found | 404 | 대상 직원·보험 적용정보 부재 — 정의처 [01_global_rules.md](./01_global_rules.md) |
| common.validation_failed | 400 | 신고자료 생성 요청 파라미터 검증 실패 — 정의처 [01_global_rules.md](./01_global_rules.md) |
