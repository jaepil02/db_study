# 05 렌더링·SEO

> **대상**: 표면별 렌더링 모드 · 프리렌더 계약 · 메타데이터와 구조화 데이터 · sitemap·robots · 공개 페이지 성능 예산 · 라우트 보호 계약
> **작성일**: 2026-08-03
> **개정일**: 2026-08-08 — 웹 프론트엔드 전환(D-20 · ADR-24) 반영 전면 재작성. 렌더링 모드를 프리렌더 정적 2본 · 법정 문서 CSR · SPA CSR로 재정의(SSG·ISR·RSC 셸 서술 제거), 미들웨어 계약을 클라이언트 라우트 가드 계약으로 대체
> **원천**: 확정 결정 D-02(최소 공개 페이지 — 수단 개정) · D-20(웹 프론트엔드 전환)([../01_overview/06_design_decisions.md](../01_overview/06_design_decisions.md)) · [09_decision_records.md](./09_decision_records.md) ADR-24 · docs_ref2/requirements_p0.md(REQ-AUT-12 공개 경로 · REQ-SYS-15·16 약관 활성 버전) · docs_ref2/features.md(SYS-11 약관·개인정보 문서 관리)

web_front는 **React + Vite + React Router 단일 애플리케이션**이며 산출물은 하나다(D-20 · ADR-24). 그 하나가 두 가지 형태로 배달된다 — 랜딩과 요금제는 **빌드 시점에 구운 정적 HTML**로, 나머지 전 경로는 **SPA 번들**로 나간다. 서버 렌더 계층·서버 미들웨어·증분 재생성 기제는 두지 않는다.

원칙은 하나다. **검색이 읽어야 하는 것만 빌드 시점에 굳히고, 나머지는 클라이언트가 그린다.** 랜딩·요금제는 사용자마다 다를 이유가 없어 정적 HTML이 가장 빠르고 안전하며, 법정 문서는 본문의 정본이 데이터베이스의 활성 버전이라 굳히는 순간 게시 문안과 동의 이력의 버전이 갈린다 — 그래서 법정 문서는 프리렌더 대상에서 빼고 클라이언트가 활성 버전을 조회해 표시한다.

본 문서는 **렌더링 전략의 정본**이다. 패키지 구성과 버전은 [../08_tech_stack/01_frontend_web.md](../08_tech_stack/01_frontend_web.md)가, 화면 명세는 [../07_screen/README.md](../07_screen/README.md)가 담당한다.

## 렌더링 모드 결정 표

| 대상 | 렌더링 | 근거 |
|------|--------|------|
| 랜딩(PUB-LANDING) · 요금제(PUB-PRICING) | **프리렌더 정적** — 빌드 시점에 HTML을 굽는다 | 사용자·세션에 따라 달라지지 않는 마케팅 콘텐츠이고 검색 노출이 목적이라 첫 바이트가 가장 빨라야 한다. 라우터 설정의 프리렌더 목록에 이 두 경로만 넣는다(ADR-24) |
| 법정 문서(PUB-LEGAL — 이용약관 · 개인정보 처리방침 · 위치기반서비스 이용약관) | **CSR** — 프리렌더 제외 · 클라이언트가 활성 버전을 조회한다 | 본문의 정본이 데이터베이스의 활성 버전(SYS-11)이라 배포 없이 개정된다. 굳히면 개정 뒤에도 옛 버전이 계속 게시되고 **화면에 뜨는 약관 버전과 동의 이력의 버전이 갈린다**. 조회로 두면 활성 버전 전환 시 재빌드·재검증이 아예 불필요해진다(D-20) |
| 미인증 인증 화면(PUB-SIGNUP · PUB-LOGIN · PUB-PASSWORD-RESET · PUB-CONSENT) | **SPA CSR** | 폼 상태·검증·에러 문안이 전부 클라이언트 상호작용이고 서버가 미리 그릴 값이 없다. 로그인 성공 직후 보호 라우트 진입까지가 한 오리진·한 산출물 안에서 끝나 복귀 대상 전달과 오픈 리다이렉트 차단이 한 곳에 모인다 |
| 관리자 웹 전 화면 | **SPA CSR** | 레이아웃·내비게이션은 클라이언트 라우터의 레이아웃 셸이 그리고 업무 데이터는 클라이언트가 API를 직접 호출한다(D-03). 검색 노출 대상이 아니며 캐시 무효화 축을 클라이언트 한 곳에 모은다 |
| 시스템 웹 전 화면 | **SPA CSR** | 위와 같다. 플랫폼 RBAC 판정은 서버 API가 하고 셸은 권한을 판정하지 않는다 |

- **레이아웃 셸에 사업장·사용자 정보를 담지 않는다.** 셸이 그린 값과 API가 돌려준 값이 다르면 어느 쪽이 맞는지 화면에서 판단할 수 없다. 셸은 골격과 스켈레톤까지다.
- **프리렌더 2본은 인증 상태로 분기하지 않는다.** 로그인 사용자에게 다른 랜딩을 보여주려면 빌드 시점 확정이 깨진다. 진입 이동은 클라이언트에서 처리한다.
- **요금제 수치는 프리렌더 셸 + 클라이언트 조회로 최신을 보장한다.** 등급·한도가 배포 없이 바뀌어도 화면에는 조회 결과가 뜨고, 검색 크롤러에는 굽힌 셸이 보인다.

### 프리렌더 계약

| 축 | 계약 |
|----|------|
| 대상 | **랜딩과 요금제 2본뿐**이다. 대상 목록은 라우터 설정 한 곳에만 두고 화면 문서와 같은 값을 쓴다 |
| 산출물 | 경로별 정적 HTML + 공용 SPA 번들이다. **산출물은 한 벌이고 배포 대상도 하나**다(D-20 · Vercel 프로젝트 1개) |
| 딥링크 | 프리렌더되지 않은 경로는 호스팅 계층의 fallback 리라이트가 SPA 진입점을 돌려준다. **프리렌더 HTML과 fallback의 우선순위는 프리뷰 배포에서 실측 확인한다**(착수 시 단서 — [08_deployment_topology.md](./08_deployment_topology.md)) |
| 법정 문서 | 프리렌더하지 않는다. 활성 버전 전환(SYS-11)이 재빌드·배포 훅을 요구하지 않으며, 게시 지연이 구조적으로 발생하지 않는다 |
| 표시 항목 | 법정 문서는 종류 · 버전 · 시행일을 본문과 함께 표시한다. **버전 없이 본문만 게시하면 어느 버전에 동의했는지 대조할 근거가 사라진다** |
| 조회 실패 | 법정 문서 조회가 실패하면 재시도 안내를 보이고 빈 본문을 게시하지 않는다 — 약관은 상시 게시 의무 대상이다 |
| 활성 버전 부재 | 종류별 활성 버전이 정확히 1개 존재함은 데이터베이스 제약이 보장한다. 활성본이 없으면 화면은 오류 상태로 남고 임의 본문을 대신 그리지 않는다 |

## SEO 계약

검색 노출 대상은 **프리렌더 2본뿐**이다. 나머지는 색인되지 않는 것이 목표다.

| 항목 | 계약 |
|------|------|
| 메타데이터 | 페이지별 title · description · canonical을 **빌드 시점 head 태그로 생성**한다. 문자열을 공용 레이아웃에 하드코딩하지 않고 각 라우트 모듈이 소유한다 |
| Open Graph | og:title · og:description · og:image · og:url · og:type · og:site_name · twitter:card를 프리렌더 2본에 둔다. 이미지는 저장소에 포함한 정적 자산이며 외부 호스트를 참조하지 않는다 |
| 언어·지역 | html lang은 ko다. hreflang 대체 언어를 선언하지 않는다 — 표시 언어가 ko-KR 단일이다 |
| 구조화 데이터 | JSON-LD로 선언한다. 대상 **3종** — 검산: Organization 1 + SoftwareApplication 1 + FAQPage 1 = **3** |
| Organization | 서비스 운영 주체 · 로고 · 연락 수단. 랜딩에 1회 선언한다 |
| SoftwareApplication | 애플리케이션 범주 · 운영체제 · 요금제(offers). 요금제 페이지에 선언하며 **등급명·한도는 요금제 정본과 같은 값**을 쓴다 |
| FAQPage | 요금제·도입 관련 질의응답. **화면에 실제로 보이는 문답만** 넣는다 — 화면에 없는 내용을 구조화 데이터로만 선언하지 않는다 |
| sitemap.xml | 빌드 산출물로 생성하며 **프리렌더 2본과 법정 문서 3본을 등재**한다. 법정 문서는 본문이 클라이언트 조회라 **lastmod를 빌드 시점에 확정할 수 없으므로 lastmod를 싣지 않는다**. **관리자·시스템·인증 경로는 등재하지 않는다** |
| robots.txt | 정적 파일로 배포한다. 공개 경로만 크롤 허용하고 **관리자·시스템·인증 경로·API 경로를 전부 차단**한다. sitemap 위치를 함께 선언한다 |
| noindex | 관리자·시스템·로그인·회원가입·가입 동의·비밀번호 재설정 경로에 noindex, nofollow 로봇 메타를 둔다. **robots.txt 차단과 메타 선언을 함께 건다** — 차단만 두면 외부 링크로 색인될 수 있다 |
| 정규 URL | 후행 슬래시·대소문자·쿼리 파라미터 변형이 별도 URL로 색인되지 않게 canonical을 명시한다 |
| 구조 | 페이지마다 h1은 하나이며 제목 계층을 건너뛰지 않는다. 이미지에는 대체 텍스트를 둔다 |

**검색 노출을 늘리기 위해 관리자 화면 일부를 공개하지 않는다.** 사업장 데이터가 담기는 표면은 색인 대상이 아니며, 본격 콘텐츠 마케팅은 v1.1이다(D-02).

## 성능 예산

측정 기준은 **모바일 4G 조건 · 75퍼센타일**이다. 값이 바뀌면 [../03_requirements/15_nonfunctional.md](../03_requirements/15_nonfunctional.md)의 REQ-NFR을 같은 변경 단위에서 함께 고친다.

| 대상 | 지표 | 목표 |
|------|------|------|
| 프리렌더 공개 페이지 | LCP | **2.5초 이하** |
| 프리렌더 공개 페이지 | CLS | **0.1 이하** |
| 프리렌더 공개 페이지 | INP | **200밀리초 이하** |
| 프리렌더 공개 페이지 | 초기 자바스크립트 전송량 | **150KB 이하**(압축 후) |
| 관리자·시스템 셸 | 셸 최초 표시 | **1.5초 이하** |
| 관리자·시스템 첫 데이터 화면 | 셸 표시 후 첫 목록 렌더 | **2.0초 이하**(API 응답 예산 포함) |

- CLS는 **크기가 확정되지 않은 요소**에서 주로 생긴다. 공개 페이지 이미지는 정적 임포트로 크기를 빌드 시점에 확정하고 width·height를 명시하며, 폰트는 셀프호스팅 woff2 + 서브셋 + 표시 전환 정책으로 치환 시 밀림을 줄인다.
- 자바스크립트 예산을 지키는 수단은 **프리렌더 페이지의 초기 청크에 인증 후 화면 코드를 섞지 않는 것**이다. 산출물이 하나라서 공용 모듈을 통해 끌려 들어오기 쉬우므로, 공개 라우트가 인증 후 전용 모듈을 임포트하지 않는 것을 규칙으로 둔다.
- 관리자 화면은 라우트 단위 코드 분할을 기본으로 하고 대형 의존성은 동적 임포트로 초기 번들에서 뺀다.

## 라우트 보호 계약

**서버 미들웨어 계층이 없다.** 진입을 가로채 판정하는 자리는 존재하지 않으며, 클라이언트 라우터 가드가 그 자리를 대신하되 **신뢰 계층이 아니라 UX 보조**다(D-20). 최종 강제는 서버 검증과 RLS 2차 방어다(REQ-AUT-12). 판정 규칙의 정본은 [02_authn_session.md](./02_authn_session.md)이고 본 절은 경로 목록을 고정한다.

### 공개 경로

미인증 상태로 진입할 수 있는 경로다. REQ-AUT-12가 정한 공개 경로에 D-02가 추가한 공개 페이지를 더한 **9종**이다.

| # | 경로 성격 | 렌더링 |
|---|----------|--------|
| 1 | 랜딩 | 프리렌더 정적 |
| 2 | 요금제 | 프리렌더 정적 |
| 3 | 이용약관 | SPA CSR |
| 4 | 개인정보 처리방침 | SPA CSR |
| 5 | 위치기반서비스 이용약관 | SPA CSR |
| 6 | 로그인 | SPA CSR |
| 7 | 회원가입 | SPA CSR |
| 8 | 비밀번호 재설정(요청 · 적용) | SPA CSR |
| 9 | 가입 동의(재동의 게이트 — 컨텍스트 발급 전 미인증 진입) | SPA CSR |

검산: 랜딩 1 + 요금제 1 + 약관 문서 3 + 로그인 1 + 회원가입 1 + 비밀번호 재설정 1 + 가입 동의 1 = **9**.

- **아이디 중복 확인은 화면이 아니라 API 경로**다(REQ-AUT-06). 라우트 가드 대상이 아니며 미인증 호출을 허용하되 빈도를 제한한다.
- **초대 수락은 웹 공개 경로가 아니다** — 직원 앱의 인증 후 화면(APP-INVITE)에서 처리한다([../07_screen/04_auth_onboarding.md](../07_screen/04_auth_onboarding.md)).
- 정적 자산 · sitemap.xml · robots.txt · 파비콘은 가드 대상이 아니다.

### 보호 경로

관리자 웹 · 시스템 웹 전 경로다. 클라이언트 가드는 인증 컨텍스트가 없다고 판단하면 로그인으로 보내고 원래 경로를 복귀 대상으로 전달한다. **복귀 대상은 내부 경로만 허용**해 오픈 리다이렉트를 차단한다.

- **가드는 자격을 확인하지 않는다.** 세션 쿠키는 HttpOnly라 스크립트가 읽을 수 없고, 가드는 부팅 시 진입 컨텍스트 조회의 성패만으로 분기한다. 그 결과가 무엇이든 화면이 여는 것은 골격뿐이며 데이터는 서버가 다시 판정한다.
- 가드를 우회해 보호 경로 번들을 직접 로드해도 얻는 것이 없다. 업무 데이터는 전부 API 응답이고 API는 세션·역할·사업장을 매 요청 재검증한다.
- **세션 유무를 스크립트가 읽을 수 있게 만들지 않는다.** 판정 편의를 위해 쿠키의 HttpOnly를 풀거나 세션 상태를 로컬 저장소에 복제하지 않는다.

## 하지 않는 것

- **웹 호스팅 계층에 업무 데이터 경로·프록시를 두지 않는다.** 서버 변이 경로도 API 중계 경로도 만들지 않으며, 인증 후 데이터 경로는 API 서브도메인 직접 호출 하나다(D-03 · D-20).
- **서버 렌더 계층과 서버 미들웨어를 두지 않는다.** 웹 산출물은 정적 HTML과 번들뿐이며 요청 시점에 실행되는 웹 서버 코드가 없다.
- **증분 재생성·온디맨드 재검증을 쓰지 않는다.** 배포 없이 바뀌는 콘텐츠(법정 문서 · 요금제 수치)는 클라이언트 조회로 최신을 보장한다.
- **프리렌더 페이지를 인증 상태로 분기하지 않는다.** 분기하는 순간 빌드 시점 확정이 깨진다.
- **국제화 다국어를 v1에 두지 않는다.** 표시 언어는 ko-KR 단일이고 통화는 원, 시간대는 KST 고정이다. hreflang·로케일 라우팅을 미리 만들지 않는다.
- **관리자·시스템 화면을 검색에 노출하지 않는다.** sitemap 등재·크롤 허용·색인 허용 어느 것도 하지 않는다.
- **약관 본문을 저장소 파일로 이중 관리하지 않는다.** 정본은 데이터베이스의 활성 버전이며 게시 화면은 그것을 조회한다.
- **공개 페이지를 별도 사이트·별도 배포 대상으로 분리하지 않는다.** 산출물이 갈리면 디자인 토큰·폰트·API 타입이 이중화되고 약관 게시 경로가 둘이 된다(D-20).
- **본격 콘텐츠 마케팅 표면(블로그·사례·검색 유입 랜딩 다수)을 v1에 두지 않는다.**
