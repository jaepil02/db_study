> **원천**: docs_ref2/features_p0.md(v1 필수 94기능 선정·필수 근거·태그) · docs_ref2/features.md(전 기능 138의 설명·우선순위·비고) · docs_ref2/requirements_p0.md(에러 코드 카탈로그) · [../README.md](../README.md) 고정 기준

본 폴더는 **기능 ID({도메인}-NN)의 채번 정본**이다. 요구사항·화면·API·데이터·용어 문서는 여기서 채번한 ID를 참조만 하고 새로 만들지 않는다. 범위는 원천 docs_ref2/features_p0.md가 선정한 **v1 필수 94기능**에 2026-09-16 채택한 **4기능**(D-23)을 더한 **98기능**이며, v1.1 이월 41기능과 영구 제외 6기능은 등재하지 않는다.

기능 목록 표는 **기능ID · 기능명 · 설명 · 우선순위 4열**이다. 설명 셀은 "무엇을 하는가"에 더해 **왜 그렇게 정했는가 · 어떤 엣지케이스를 막는가 · 무엇을 차단하는가**를 함께 담는다. 원천이 태그로 표시한 필수 근거(제품성립 · 법정의무 · 계산정확성 · 플랫폼요건)는 설명 안에 녹여 서술한다.

우선순위 P0·P1·P2는 **98기능 안에서의 구현 순위**이며 v1 채택 여부와는 다른 축이다. 정의의 정본은 [../01_overview/05_priorities_roadmap.md](../01_overview/05_priorities_roadmap.md)다.

| 등급 | 기능 수 | 정의 |
|------|:-------:|------|
| P0 | 25 | 진입·테넌트·계산 전제. 없으면 서비스가 성립하지 않거나 뒤 단계가 통째로 허공이 된다 |

## 전 도메인 공통 제약 요약

아래는 전 기능이 전제하는 불변식의 **요약**이다. 계약의 정본은 [../03_requirements/01_global_rules.md](../03_requirements/01_global_rules.md)(REQ-GLB)이며, 어긋나면 그 문서가 우선한다. 각 도메인 파일은 이 표를 다시 쓰지 않는다.

| 제약 | 내용 |
|------|------|
| 멀티테넌트 격리 | 업무 테이블은 workplace_id 스코프다. 서비스 레이어 1차 검증 + PostgreSQL RLS 2차 심층방어의 **2단 방어**로 행 단위 격리를 강제하고 클라이언트 가드는 보조로만 둔다 |
| 본인 소유권 인가 | 명세서·급여이력·근로계약은 멤버십이 아니라 **본인 소유권**으로 인가한다. 퇴사·사업장 폐쇄 후에도 보존기간 내 본인 열람이 끊기지 않는다(CMP-07) |
| 규모 분기 단일 기준 | 5인·10인 분기의 유일한 근거는 CMP-01 상시근로자 스냅샷이다. 사업장 속성·수동 플래그·활성 멤버 수로 분기하지 않으며, **규모는 고정 속성이 아니라 기준일의 함수**다 |
| 규모별 적용 = 화이트리스트 | 근로기준법 시행령 별표 1은 5인 미만에 **적용되는** 조문만 열거한다. 목록에 없으면 미적용이며, 블랙리스트로 오해하면 분기가 통째로 뒤집힌다. 분기는 조문 단위 정책값(CMP-02)으로 관리한다 |
| 계산 결정론 | 급여 계산은 서버 전용·룰 기반이다. 동일 입력 = 동일 결과이며 AI 추론 · 실행 시각 의존 · 부동소수점 누적을 금지한다 |
| 부동소수점 금지 | 금액은 정수(원) · 시간은 정수(분) · 비율은 고정소수점 십진만 쓴다 |
| 단수 처리 | 항목별 **최종 금액에서 1회만** 적용한다. 지급 = 올림 · 무급공제 = 절사 · 법정공제 = 10원 미만 절사. **최저임금 환산액은 반올림하지 않는다** |
| 기준값 선택 단위 | 연도가 아니라 **귀속 기준일**이다. 간이세액표는 지급일, 국민연금 상하한은 7월 경계다 |
| 기준값 누락 차단 | 필요한 기준값이 하나라도 없으면 계산을 차단한다. 임의 기본값·직전 연도 값 대체·0 처리를 금지한다 |
| 결과 값 동결 | 확정 시 기준값 행 ID + 실제 값 · 상시근로자 스냅샷 · 정책/규칙 버전을 결과에 동결 저장한다. 이력 조회만으로는 재현이 깨진다 |
| 확정 불변·정정 체인 | 확정 결과는 덮어쓰지 않는다. 정정은 원본 VOID → supersedes 연결 정정본 신규 생성으로만 한다 |
| 멱등성·동시성 | 확정·발행·정기작업·외부 호출은 멱등키로 중복 부수효과를 막고, 경합은 트랜잭션 잠금으로 차단한다 — **멱등성은 경합을 막지 못한다** |
| 권한 분리 | 본인 요청 본인 승인을 차단한다. 본인이 대상자로 포함된 급여의 확정은 **OWNER 전용**이다 — 자기포함 표시 + MANAGER 실행 차단(auth.workplace_forbidden/403) + 감사 기록을 모두 수행한다 |
| 법정 보존 | 기산일이 유형별로 다르다 — 근로계약서 = 종료일+3년 · 임금대장 = 마지막 기입일+3년 · 근로자명부 = 퇴직일+3년 · 명세서 = 지급일+3년. 재직 중 만료를 금지한다 |
| 민감정보·위치정보 | 주민번호·계좌는 암호화 + blind-index + 마스킹이며 평문 열람은 재인증·사유·감사·서버 1회성 응답을 요구한다. 개인위치정보는 별도 동의가 선행하고 이용·제공 사실 확인자료를 자동 기록한다 |

## 결번 규약

접두사별 01부터 연속 채번하는 것이 원칙이나, **기능ID의 결번은 오류가 아니라 v1 범위 제외를 뜻하는 의도된 공백**이다.

- 결번·폐지 ID는 **재사용하지 않는다**. 이월 기능이 v1.1에 들어올 때 원래 번호를 그대로 쓴다.
- v1 제외 기능ID의 유일한 등재처는 [../01_overview/02_goals_scope.md](../01_overview/02_goals_scope.md) Out 범위 표다. 본 폴더를 포함한 다른 문서는 부정형 언급만 한다.
- 결번 예 — HRM-10(인사 변경 이력)은 v1.1 이월이라 [03_hr.md](./03_hr.md)에 없다. **이월 기능이 v1로 들어오면 원래 번호로 등재한다** — AUT-05 · ATT-10 · DSH-03 · DSH-06이 그 예다(D-23). WRK-13(ADVISOR 초대)이 이월되었으므로 **ADVISOR 역할은 v1에 두지 않으며**, 원천 문서의 "ADVISOR 조회 가능" 서술도 v1.1 이월로 조정해 등재하지 않는다.
- 채번 규약 상세의 정본은 [../09_glossary/04_id_conventions.md](../09_glossary/04_id_conventions.md)다.
